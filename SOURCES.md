# Источники учебников по странам

## Россия 🇷🇺

### Работающие источники:
- **archive.org** — основной источник
  - Поиск: `"учебник История России" filetype:pdf`
  - Поиск: `"учебник Русский язык" 9 класс`
- **elibrary.ru** — российские издания (может требовать аккаунта)
- **fb2.top, flibusta** — электронные книги
- **Издательства:**
  - Просвещение (prosveshchenie.ru)
  - Дрофа (drofa.ru)
  - Мнемозина (mnemozina.ru)

### URL паттерны:
```
https://archive.org/search?query=учебник+История+России+9+класс&mediatype=texts
https://archive.org/search?query=учебник+Русский+язык+9+класс&mediatype=texts
https://archive.org/search?query=учебник+Литература+9+класс&mediatype=texts
```

## Казахстан 🇰🇿

### ОСНОВНОЙ ИСТОЧНИК: **OKULYK.KZ** ⭐

**Сайт:** https://okulyk.kz/

**Как скачать:**
1. Перейди на okulyk.kz
2. Выбери класс (9, 10, 11)
3. Выбери предмет
4. Книга откроется в онлайн-читалке
5. Меню → Скачать → PDF

**Предметы:**
- Қазақстан тарихы (История Казахстана)
- Әлем тарихы (Всемирная история)
- Қазақ тілі (Казахский язык)
- Әдебиет (Литература)

### Альтернативные источники:
- **bilimland.kz** — образовательный портал
- **archive.org** — поиск с латиницей

## Общие стратегии поиска

### 1. Archive.org (Интернет-архив)
```
https://archive.org/search.php?query=textbook+<COUNTRY>+grade+<9|10|11>&mediatype=texts
```

### 2. Google Scholar
```
https://scholar.google.com/scholar?hl=en&q=<subject>+<COUNTRY>+textbook+filetype:pdf
```

### 3. Google Books
```
https://books.google.com/
```

### 4. Z-Library
```
https://z-library.sk/
```

### 5. LibGen
```
https://libgen.is/
```

## Советы по поиску

✅ **Работает:**
- Поиск на нативных языках (кириллица, латиница, спецсимволы)
- Вариации названий: "подручник", "учебник", "textbook"
- Старые издания (часто свободнее распространяются)
- Официальные порталы + archive.org

❌ **Не работает:**
- Транслитерация на английский
- Слишком специфичные требования (ровно 2015 год издания)
- Недавние издания (могут быть под авторским правом)

---

## Правовые замечания ⚠️

- Большинство старых советских/постсоветских учебников свободны от авторских прав
- Современные учебники часто защищены авторским правом
- Проверяй лицензию перед скачиванием
- Используй для образовательных целей

## Как добавить новый источник

1. Найди рабочий URL
2. Проверь, что скачивается PDF
3. Обнови `sources.json`:
   ```json
   "Country": {
     "subject": {
       "grade": ["https://new-url.com/file.pdf"]
     }
   }
   ```
4. Сделай PR или создай Issue
